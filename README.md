# SiroPHP Landing Page

The official website for **SiroPHP** — the zero-dependency PHP API framework with built-in debugging, AI integration, and enterprise security.

Built with Next.js 16 + TypeScript + Tailwind CSS.

## Pages

25+ static pages: docs, blog (8 articles), benchmarks, features, FAQ, examples, tutorials, install guide, replay demo, security, privacy, terms.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm test` | Vitest |
| `npm run lint` | ESLint |

## Deploy

Supports Vercel, Docker, static export.
